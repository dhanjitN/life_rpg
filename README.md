# Getting Started 
## Web & Api Folder 
### WEB
#### Tech Stack - React + TypeScript 
#### Styling -> Tailwindcss + shadcn 

- go inside the web folder 
- use bun/pnpm/npm to install the required modules
```
bun install 
```
- start the server
```
bun run dev 
```

### API
### Tech Stack - Hono + mongoDB 
- go inside the api folder 
- use bun/pnpm/npm to install the required modules

```
bun install 
```
- start the server
```
bun run dev 
```
